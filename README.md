# MERIDIAN

Creative studio demo site. Cinematic, multi-page, WebGL-selective.

## Dev
- `npm run dev` — local dev server
- `npm run build` — production build
- `npm test` — unit tests (Vitest)
- `npm run typecheck` — TypeScript
- `npm run lint` — ESLint
